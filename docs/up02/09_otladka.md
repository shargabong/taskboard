# Этап 9. Отладка и проверка по спецификации

## 9.1. Что отлаживалось

- вход и сессия;
- роли;
- создание задачи;
- комментарии;
- переходы статусов;
- доступ к чужим задачам;
- подключение к SQLite и PostgreSQL;
- Docker и release build.

## 9.2. Режимы

| Переменная | Что делает |
| --- | --- |
| `TASKBOARD_DEBUG` | Выводит SQL-запросы |
| `TASKBOARD_ENVIRONMENT` | Название среды |
| `TASKBOARD_SEED_DEMO` | Демо-данные |
| `TASKBOARD_SESSION_HTTPS_ONLY` | Cookie только по HTTPS |
| `TASKBOARD_DATABASE_URL` | SQLite или PostgreSQL |
