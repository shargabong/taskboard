## 8.3. До и после

### Длинные строки

До: длинные `session.add(Comment(...))` в `seed.py`.

После: `ruff format` разбил строки, E501 больше не срабатывает.

### Docker в PATH

До: скрипт backup падал, если `docker` не в PATH.

После: скрипт ищет Docker Desktop в `%LOCALAPPDATA%`.

### Порт базы

До: в release compose PostgreSQL был доступен наружу.

После: порт базы не публикуется, приложение ходит к ней по внутренней сети.
