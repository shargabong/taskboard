# Changelog

## [0.1.0] - 2026-11-04

### Добавлено

- вход и роли: администратор, руководитель, сотрудник;
- создание задач и список с фильтрами;
- карточка задачи и комментарии;
- статусы: новая, в работе, выполнена;
- назначение исполнителя;
- управление пользователями;
- сводка на главной;
- healthcheck `/health`;
- 16 тестов и ruff;
- Dockerfile, compose и release compose;
- CI и release workflow в GHCR;
- backup и restore PostgreSQL;
- документы УП02 и УП03.

### Исправлено

- backup без папки `backups`;
- поиск Docker не в PATH;
- некорректные переходы статусов;
- доступ к чужой задаче;
- длинные строки и импорты.

### Известные ограничения

- нет CSRF;
- нет rate limit;
- нет миграций;
- демо-пароли;
- нет внешнего мониторинга.
