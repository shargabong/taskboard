# УП03. Баг-репорт

## BUG-01. Backup не создавал файл

| Поле | Значение |
| --- | --- |
| Серьёзность | Высокая |
| Компонент | `make backup` |
| Статус | Исправлен |

**Шаги:**

1. Запустить backup.
2. Проверить папку `backups`.
3. Попробовать restore.

**Ожидание:** файл дампа есть, restore проходит.

**Факт:** файла нет, restore падает на отсутствии таблиц.

**Причина:** нет папки `backups`, нет проверки ошибки.

**Исправление:** папка создаётся, код возврата проверяется, добавлен fallback Docker.

## BUG-02. Docker не найден в PATH

| Поле | Значение |
| --- | --- |
| Серьёзность | Средняя |
| Компонент | Скрипты backup и restore |
| Статус | Исправлен |

**Причина:** Docker Desktop установлен в пользовательскую папку и не попал в PATH.

**Исправление:** скрипт ищет `%LOCALAPPDATA%\Programs\DockerDesktop\resources\bin\docker.exe`.
