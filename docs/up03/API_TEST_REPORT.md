## 3. Сценарий

1. Руководитель входит.
2. Создаёт задачу.
3. Добавляет комментарий.
4. Переводит задачу в работу.
5. Завершает задачу.
6. Открывает список.
7. Администратор открывает главную, задачи и пользователей.

Все шаги вернули 200.
