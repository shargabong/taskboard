# УП03. План тестирования

## 1. Цель

Проверить, что TaskBoard работает по ТЗ, роли ограничены, данные сохраняются, Docker и release build запускаются.

## 2. Виды тестов

| Вид | Инструмент |
| --- | --- |
| Модульные | pytest |
| Интеграционные | pytest + TestClient |
| Функциональные | smoke-скрипт API |
| Производительность | httpx, последовательные запросы |
| Безопасность | checklist, pip-audit |
| Восстановление | pg_dump и restore |

## 4. Критерии входа

- приложение запускается;
- база создаётся;
- демо-данные есть;
- зависимости установлены.

## 5. Критерии выхода

- 15 тестов проходят;
- ruff чистый;
- `/health` 200;
- основной сценарий прошёл;
- отчёты заполнены.

## 6. Метрики

| Метрика | Цель | Факт |
| --- | --- | --- |
| Автотесты | 100% | 15 из 15 |
| Ошибки линтера | 0 | 0 |
| Критические дефекты | 0 | 0 |
| `/health` среднее | до 50 мс | 1.8 мс |
| `/tasks` среднее | до 200 мс | 4.4 мс |

## 7. Вывод

План покрывает ключевые сценарии и инфраструктуру. Тестирование выполнено, результаты в отдельных отчётах.
